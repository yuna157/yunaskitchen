YUNA'S KITCHEN PWA 설치 방법

이 저장소를 GitHub Pages로 배포하면 설치형 PWA로 사용할 수 있습니다.

[갤럭시]
1. GitHub Pages 주소를 Chrome에서 엽니다.
2. 오른쪽 위 점 3개 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 누릅니다.
3. 홈 화면의 YUNA'S KITCHEN 아이콘으로 실행합니다.

[iPhone]
1. 같은 GitHub Pages 주소를 Safari에서 엽니다.
2. 공유 버튼을 누릅니다.
3. '홈 화면에 추가'를 선택합니다.
4. 홈 화면의 YUNA'S KITCHEN 아이콘으로 실행합니다.

[데이터]
- 2026-09-21 백업 JSON의 레시피/카테고리/TO COOK 데이터를 초기값으로 반영했습니다.
- 앱 안의 기록 > DATA BACKUP에서 JSON 백업/복원이 가능합니다.
- 휴대폰 교체 전에는 JSON 백업을 별도로 보관하는 것을 권장합니다.
